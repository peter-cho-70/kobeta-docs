- AI와 함께 창작하는 언리얼 가상세상(생성형 AI 툴 연계, Previz)
- 예능·교양 프로그램 가상환경 제작 실무 전략(XR 스튜디오 구성)
- 실습으로 익히는 AI 기반 언리얼 환경 구현(실습&피드백)

**강사 풀**
- KBS 후반제작기술국 박지민 감독 — 언리얼 엔진 전반(1~2일차 단독 강의)
- KBS 후반제작기술국 김태환 팀장 — AI×언리얼 가상세계 구성, 예능/교양 가상환경 실무전략, 실습 피드백(3일차)

- **지역 교육(제주·전남·경남·울산)은 1일형 세미나 포맷**: 본사 3일 과정과 달리 지역 교육은 1일, 2~3개 세션 구성이 일관됨. 지역 교육 기획 시 이 1일형 포맷(개회→세션1→세션2)을 기본 틀로 사용 가능.
- **세미나/컨퍼런스는 인력양성 실적에서 제외되는 규정이 반복 적용**: 2022년(KOBA World Media Forum, KOC)과 2025년(Broadcast TechCON 2025) 모두 동일 규정 적용. 차년도 사업 설계 시 세미나형 행사와 정규 커리큘럼형 과정을 구분해서 목표 인원을 산정해야 함.
- **AI 코딩 실습형 과정(바이브코딩, Claude Code)의 등장**: 기존 방송장비/제작기술 중심에서 "방송기술인이 직접 코딩하여 자동화 도구를 만드는" 방향으로 과정 성격이 확장됨(RAG QnA봇, 자막 자동생성, 금칙이미지 검출 등). 향후 과정 기획 시 "현업 문제 해결형 프로젝트 실습" 포맷이 유효할 것으로 보임.
- **정보 공백이 큰 과정들(A-2, A-3, B)**: `과정.csv`만으로는 만족도, 상세 시간표, 전체 강사 명단을 알 수 없는 과정이 다수 존재. 2025년도 사업의 경우 2022년처럼 별도 결과보고서 PDF(Downloads에 존재)를 추가로 분석하면 이 공백을 채울 수 있음.

## 5. 자료 정확도에 관한 비고

- `과정.csv`는 작성 형식이 표마다 달라(일부는 요약표, 일부는 시간표만, 일부는 정식 과정명 누락) 본 문서로 재구성하는 과정에서 다음을 추정/보완했습니다: C-4(경남권 특강), D-2/D-4/D-5/D-6(과정명에 "(추정 명칭)" 표시), B(가제 부여).
- D-3(2025년 10월, 바이브코딩)와 D-6(2026년 7월, ComfyUI)의 실제 정식 명칭은 Downloads 폴더의 공문/안내서 파일명("바이브코딩으로 완성하는 생성형 AI 서비스(초급)" 등)을 참고해 확인된 것이며, 나머지 추정 명칭은 확인되지 않았으므로 사용 전 원본 공문 대조를 권장합니다.
- 동일인 추정(전성호, 강진욱, 이형극, 임종근, 김승준, 김정훈, 김태현/김태헌)은 소속·주제 유사성에 근거한 추론이며, 확정 정보는 아닙니다.
- A(2025년 AI 방송직군별 역량강화 교육) 5개 과정은 별도의 결과보고서 PDF가 Downloads에 존재하므로, 더 상세한 만족도·강사풀·시간표 정보가 필요하면 해당 PDF를 추가로 분석해 본 문서를 보강할 수 있습니다.
