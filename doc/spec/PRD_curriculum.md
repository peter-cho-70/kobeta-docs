# PRD: KBTE 교육 커리큘럼 설계 플랫폼

**문서 버전**: v0.3 (연간 사업계획서 분석 반영 — 예산/성과지표/사업관리 레이어 추가)
**작성일**: 2026-06-19
**작성 대상**: 한국방송기술교육원(KBTE) 교육기획팀

> 본 개정판은 ① "[3D Audio 및 Immersive Sound 실전]" 3일 과정 교육 안내서(2025년 9월, v0.2 반영)에 더해, ② "2026년도 AI 방송직군별 역량강화 교육 개발·운영 사업계획서"(2026년 3월) 전체를 분석하여 반영했습니다. 두 번째 문서는 단일 과정이 아니라 **연간 단위로 6개 과정 + 2개 세미나를 묶은 "사업" 전체**의 기획서로, 목표·예산·성과지표·추진일정·홍보계획·강사료 등급체계·조직정보까지 포함하고 있어 시스템 범위를 한 단계 더 넓혀야 한다는 것을 확인했습니다.

---

## 1. 배경 및 목표

KBTE는 1일/2일/3일 등 다양한 기간의 교육과정을 분야별로 설계하고 있습니다. 현재는 교육 분야, 강사 정보, 이론/실습 시간 배분 등의 자료가 문서나 개인 경험에 흩어져 있어, 매번 커리큘럼을 처음부터 설계하는 데 시간이 많이 소요될 것으로 예상됩니다. 또한 교육이 끝난 뒤의 강사 피드백이나 수강생 후기가 다음 커리큘럼 설계에 체계적으로 반영되기 어려운 구조일 가능성이 높습니다.

**제품 목표**

1. 교육 분야·과정·강사 데이터를 사전에 표준화하여 재사용 가능한 "교육과정 Pool"로 관리
2. Pool에서 과정을 드래그앤드롭으로 조합해 일자별 커리큘럼 초안을 빠르게 작성
3. 주제·기간·장소만 입력하면 AI가 1차 초안을 자동 구성하여 기획 시간을 단축
4. 강사 풀(연락처/자료/이메일)을 한 곳에서 관리하고 일정 안내를 자동화
5. 교육 종료 후 강사 피드백과 수강생 후기·현업 적용사례를 수집해 과정 품질을 지속적으로 개선하는 **선순환 구조** 구축

## 3. 핵심 컨셉

본 플랫폼은 두 개의 계층으로 동작합니다.

> **사업계획서 분석으로 새로 확인된 점**: 기존 설계는 "교육과정(3일짜리 커리큘럼) 1건"을 만드는 데 초점이 맞춰져 있었습니다. 그런데 실제로는 그 위에 **연간 단위의 "사업(Program)"**이 있고, 하나의 사업이 여러 개의 교육과정과 세미나를 묶어 예산·성과지표·추진일정을 함께 관리하고 있었습니다(예: "2026 AI 방송직군별 역량강화" 사업 = 1억7천만원 예산, 6개 과정 + 2개 세미나, 수료 90명·만족도 85% 등 KPI 포함). 이에 따라 컨셉을 아래와 같이 2계층으로 재정의합니다.

1. **사업(Program) 계층**: 연간 예산·정량/정성 목표·성과지표·추진일정·홍보계획을 가진 상위 단위. 보통 1개 사업 = 여러 개의 교육과정/세미나로 구성
2. **교육과정(Course) 계층**: 기존에 설계한 "사전 데이터 체계화 + 드래그앤드롭 커리큘럼 빌더"가 그대로 적용되는 단위 (1개 과정 = 3~4시간짜리 과정 카드 여러 개의 조합)

이 위에 AI 자동 초안 생성과 교육 후 피드백 루프가 더해져, "사업 기획 → 과정 설계 → 운영 → 피드백/정산 → 다음 사업 기획에 반영"이 순환되는 구조를 목표로 합니다.

```
[연간 사업(Program): 목표·예산·KPI·추진일정·홍보계획]
        │
        ├─▶ [교육과정 A: 카테고리/강사 마스터 데이터 → Pool → 드래그앤드롭 → 확정 커리큘럼]
        ├─▶ [교육과정 B: 동일 구조]
        └─▶ [세미나/포럼: 간소화된 1일 구조]
                  │
                  ▼
        [강사 사후평가] + [수강생 후기/적용사례] + [예산 집행/성과지표 실적]
                  │
                  ▼
        [사업 성과보고 → 다음 연도 사업계획에 반영]
```

## 4. 기능 요구사항

### 4.1 사전 데이터 관리 (마스터 데이터)

- **교육분야 카테고리**: 대분류/중분류 트리 구조 (예: 방송기술 > 카메라/촬영, 영상편집, 송출/중계, 음향, AI/뉴미디어 등). 카테고리 추가/수정/비활성화 관리
- **이론/실습 시간 배분 기준**: 분야별 권장 비율(예: 이론 40% : 실습 60%)을 기본값으로 설정해두고, 개별 과정에서 override 가능
- **강사 마스터 데이터**: 이름, **소속기관(예: KBS TV기술국, SBS 방송기술팀), 직급/직책(예: 팀장, 음향감독)**, 전문분야(복수 카테고리 매핑), 경력/약력, 이메일, 연락처, 강의 가능 요일/시간대, 기본 강의료, 보유 교육자료 링크
  - 실제 사례 분석 결과 KBTE 강사진은 자체 직원이 아닌 **KBS·SBS 등 현업 방송사 소속 전문가, 프리랜서 강사, 학계/연구기관, 해외 전문가**까지 폭넓게 포함됩니다.
- **강사료 등급 기준표 (신규)**: 사업계획서에서 확인된 항목으로, 소속(방송사/대학/연구기관/기업체/초빙)별로 등급(초빙·책임급A·선임급B·원급C·D·E·내부강사)을 정의하고 등급별 시간당 단가를 마스터로 관리. 강사를 등록할 때 이 등급에 매핑해두면, 커리큘럼 빌더에서 과정을 배치하는 즉시 **강사료가 자동 계산**됩니다(아래 4.9 참고). 국외 강사는 등급(책임급/선임급)별 달러 단가 및 항공료/체재비 기준도 별도 관리합니다.
- **운영 담당자(Coordinator) 마스터 데이터**: 이름, 직급(예: 차장), 이메일, 전화번호 — 강사와 별도 역할로, 교육 안내문의 "담당자/문의사항"란에 노출되고 보통 1개 과정에 2인 내외가 배정됩니다.
- **모집/운영 정책 기준값**: 정원 기본값, 교육비 정책(무료/유료), 중식 지원 여부, 주차 지원 여부(예: "2시간 무료"), 온라인 진행 가능 여부, 접수 방식(선착순/심사), 지역·소속 우선순위 차수(예: 경기도 사업 연계 시 "경기도 소재자 1차 → 외 지역 2차"), 제출 증빙서류 안내문구
- **기관 프로필 마스터 데이터 (신규)**: 사업계획서 작성 시 매번 반복 입력되는 KBTE 자체 정보 — 기관명/사업자번호/주소/연락처, 조직도, 인력현황(원장/실장/차장 등), 연혁, 과거 사업실적 이력(연도별 사업명·기간·계약금액·발주처). 한 번 등록해두면 사업계획서 자동 생성(4.12) 시 "V. 신청사 현황" 장에 그대로 재사용됩니다.
- **교육대상 기관 마스터 데이터 (신규)**: 사업계획서에 포함된 "지상파/지역MBC/민방/종교방송/공동체라디오" 등 교육 대상 방송사·기관 리스트를 마스터로 등록해두면, 모집 시 사별 인력 현황 기반 균형 배분(4.11에서 다룰 공정 모집 로직)에 활용 가능

### 4.2 교육과정 Pool (과정 카드 시스템)

하나의 "과정 카드"가 교육과정 풀의 최소 단위입니다.

> **실제 사례로 본 카드의 단위**: 두 샘플을 비교해보니 카드(모듈)의 기본 시간 단위가 과정마다 다릅니다 — 3D Audio 과정은 3~4시간 단위였지만, AI 역량강화 과정들은 **2시간 단위 모듈**을 반나절에 2개씩 배치하는 구조였습니다(예: "Claude Code와 바이브 코딩 이해" 2H + "Claude Code 실무 활용 흐름 파악" 2H = 오전 4시간). 따라서 카드의 소요시간은 고정값이 아니라 **1~4시간 사이의 자유 입력값**으로 설계하고, 빌더는 어떤 길이의 카드든 시간 슬롯에 맞춰 배치할 수 있어야 합니다.

**과정 카드 속성**
- 과정명(대주제), 소속 카테고리, 난이도 등급(초급/중급/고급)
- 이론 시간 / 실습 시간 / 총 소요시간 (1~4시간 자유 입력, 과정 성격에 따라 단위가 다름)
- **세부 학습내용**: 대주제 하위에 보통 2~4개의 bullet (예: "180도 이머시브(WFS) 사운드 제작사례 / 시스템 구축 / 제작 실전")
- 담당 가능 강사(복수 매핑, **주강사/보조강사 구분**) — 표시 시 "소속기관 + 이름 + 직급"으로 노출 (예: "SBS 방송기술팀 조형곤 음향감독")
- 선수과목(이 과정을 듣기 전에 필요한 과정)
- 교육자료 첨부
- 누적 데이터: 평균 만족도 점수, 최근 강사 피드백 요약, 진행 횟수

**과정(상위 단위) 개요 블록 (신규)**: 사업계획서에서 확인된, 카드보다 한 단계 위인 "과정" 전체에 붙는 표준 메타데이터입니다. 3일 과정 전체(예: "파이썬 기반 방송 데이터 분석 및 AI 자동화 실무")에 한 번만 입력하면 안내문/사업계획서에 일관되게 노출됩니다.
- 과정 개요(1~2문장 요약), 교육 목표(bullet 3~5개)
- 교육환경/실습환경(예: "실습 강의실(PC, 음향장비 등)")
- 활용 장비(예: "고성능 노트북")
- 교재 형식(예: "PDF 파일")
- **활용 SW/도구 태그 리스트** (예: n8n, Claude Code, ComfyUI, Whisper, OpenAI API 등) — 과정 검색/필터에 활용되고, 안내문에도 표기

**과정 카드 매핑 예시** (업로드된 샘플 기준)

| 카드명 | 시간 | 강사 | 세부 학습내용 |
|---|---|---|---|
| 이론 & 동향 | 3H | KBS 임영재 팀장 | 이머시브 사운드 정의와 분류, 스테레오 vs 공간음향, 인터랙티브 오디오와 AI적용 |
| 이머시브 시스템 | 4H | SBS 조형곤 음향감독 | 네트워크 오디오의 이해, 시스템 구축, 스피커 튜닝 |
| 180도 WFS 이머시브 사운드 | 3H | SBS 조형곤 음향감독 | 제작사례, 시스템 구축, 제작 실전 |
| 3D Binaural 및 Dolby Atmos | 4H | KBS 임영재 팀장 | 제작사례, Binaural 실전, Atmos 실전Ⅰ |
| Dolby Atmos & MPEG-H | 3H | KBS 임영재 팀장 | Atmos 실전Ⅱ, MPEG-H 제작사례·실전 |
| 360도 이머시브 사운드 | 3H | SBS 조형곤 음향감독 | 제작사례, 시스템 구축, 제작 실전 |
| Claude Code와 바이브 코딩 이해 | 2H | SideOnAI 김태헌 대표 | 개념 이해, 환경 설치(Node.js 등), 터미널 명령어 실습 |
| 오디오 추출 및 음성 인식 | 2H | SideOnAI 김태헌 대표 | 오디오 추출, Whisper 연동, STT 결과 품질 점검 |

이렇게 카드 단위로 풀에 등록해두면, 이번 과정뿐 아니라 다음에 "심화반"이나 "단기 1일 특강"을 짤 때도 동일 카드를 재사용할 수 있습니다.

**시각적 구분 (요청하신 색상 아이콘 체계)**
- 1차 구분 — **등급별 색상**: 초급(녹색) / 중급(파랑) / 고급(보라)
- 2차 구분 — **아이콘 형태로 이론/실습 비율 표현**: 이론 중심(책 아이콘) / 실습 중심(도구 아이콘) / 혼합형(반반 아이콘), 또는 카드 테두리 두께·패턴으로 실습 비중을 표현하는 방식도 검토 가능
- 카드 우측 상단에 총 소요시간 배지(예: "3H") 표시
- 색상+아이콘의 이중 인코딩으로 한눈에 "어떤 분야·난이도·유형"인지 식별 가능하도록 설계

**Pool 화면 구성**
- 좌측 카테고리 트리로 필터링, 상단 검색창, 난이도/시간 필터
- 카드 그리드 뷰 (드래그 시작점)
- 즐겨찾기, 최근 사용 과정 표시

### 4.3 드래그앤드롭 커리큘럼 빌더

- **레이아웃**: 좌측 과정 Pool, 우측 일자별 바구니(Day 1, Day 2, Day 3… 필요한 만큼 추가)
- 각 Day는 시간 슬롯(예: 09:00~18:00)을 가지며, 카드를 드래그해서 순서대로 배치
- **자동 계산**: 배치된 과정들의 합산 시간을 표시하고, 일일 정규 교육시간 대비 초과/여유 시간을 경고
- **충돌 감지**: 동일 강사가 같은 시간대 다른 과정에 중복 배치되면 경고 표시
- **고정 세션 자동 삽입**: 실제 운영 사례를 보면 모든 과정에 거의 동일한 틀이 반복됩니다 — 첫날 시작 전 "교육사업 안내"(보통 20분), 매일 "중식"(보통 1시간 30분), 마지막날 종료 직전 "설문조사 및 종료"(보통 10분). 이 세 가지를 시스템 기본 템플릿으로 제공해 빌더가 Day를 생성할 때 자동으로 깔아주고, 담당자는 시간만 조정하면 되도록 합니다.
- 카드 내 순서 변경(재정렬), 개별 과정 메모 추가, 삭제
- 완성된 초안은 "커리큘럼 프로젝트"로 저장, 이후 PDF/문서로 내보내기 가능 (자세한 내용은 4.8 참고)

### 4.4 AI 자동 커리큘럼 초안 생성

- **입력값**: 교육 주제(또는 목표 역량), 총 교육일수, 1일 교육 가능시간, 교육 장소 특성(실습실 유무, 장비 보유 여부), 수강생 수준(신입/실무자/관리자 등)
- **AI 동작**: Pool 내 과정들을 조합하여 난이도가 점진적으로 올라가는 순서, 이론/실습 균형, 강사 가용성을 고려한 일자별 초안을 자동 배치
- **추천 근거 표시**: 단순히 결과만 주는 것이 아니라 "실습 비중을 60%로 맞추기 위해 OO과정을 포함했습니다", "오전에는 이론, 오후에는 실습으로 배치했습니다" 같은 근거를 함께 제시해 신뢰도 확보
- 생성된 초안은 바구니에 자동 배치된 상태로 나타나며, 사용자가 자유롭게 수정/삭제/순서변경 가능 (AI는 시작점 제공, 최종 결정은 사람)

### 4.5 강사 Pool 관리

- 강사 프로필 카드: 연락처, 전문분야, 담당 가능 과정 매핑, 강의 이력
- **이메일 관리**: 커리큘럼이 확정되면 해당 강사에게 일정 안내 메일을 자동 발송 (날짜, 시간, 장소, 담당 과정 정보 포함)
- **교육자료 저장소**: 강사별 업로드 자료를 버전 관리 (이전 강의안과 최신본 구분)
- **강사 스케줄 캘린더**: 가용성을 한눈에 확인, 외부 캘린더(구글/아웃룩) 연동 검토

### 4.6 사후관리 — 강사 피드백 루프

- 교육 종료 후 강사에게 자동으로 피드백 입력 요청 (자기평가)
  - 잘된 점, 개선이 필요한 점
  - 수강생 반응/이해도 체감
  - 추가로 필요하다고 느낀 보충 교육 제안
  - 자료/시간 배분 수정 의견
- 입력된 피드백은 **해당 과정 카드의 이력에 누적**되어, 다음 커리큘럼 설계 시 카드에 "최근 강사 피드백" 배지로 노출
- 과정 자료/시간 배분에 변경이 생기면 버전 이력으로 기록 (무엇이, 왜 바뀌었는지 추적 가능)

### 4.7 수강생 후기 및 현업 적용사례 수집

- 교육 종료 직후 설문 자동 발송: 만족도, 난이도 적정성, 강사 만족도, 자유 의견
- 일정 기간 경과 후(예: 1~3개월) 후속 설문: "교육 내용을 실제 업무에 어떻게 적용했는지" 사례 수집
- 우수 적용사례는 별도 아카이브로 정리하여 추후 커리큘럼 소개 자료나 성과 보고에 활용
- 과정 카드에 평균 만족도 점수와 적용사례 링크를 노출하여, 다음 커리큘럼 구성 시 신뢰도 지표로 참고

### 4.8 교육 안내문(공문) 자동 생성

업로드해주신 안내서 자체가 KBTE의 표준 산출물 양식이라는 것을 확인했습니다. 빌더에서 완성한 데이터를 그대로 이 양식의 PDF로 내보내는 기능을 핵심 출력 기능으로 추가합니다.

- **자동 매핑되는 항목**
  - 표지: "OOOO년 OO월 교육과정" + 과정명
  - 1. 교육목적: 과정 카드들의 학습목표를 조합해 초안 생성 (사용자 수정 가능)
  - 2. 교육일정: 빌더의 Day 구성에서 시작일~종료일·총 일수 자동 계산, 정원·장소·온라인 여부는 마스터 데이터에서 가져옴
  - 3. 접수방법: 모집정책(4.1) 기준값(접수방식, 지역우선순위 차수, 증빙서류 안내)을 템플릿 문구로 자동 생성
  - 4. 기타: 교육비/중식/주차 지원여부, 운영 담당자 2인 표기, 문의 전화·이메일
  - 교육 커리큘럼 표(2페이지 분량): Day·시간·소요시간·강사(소속+이름+직급)·교육내용(대주제+세부 bullet)을 빌더 데이터에서 그대로 표로 변환
- 출력 형식: PDF (필요 시 Word/HWP 변환도 검토 가능 — 공공기관 특성상 한글(HWP) 호환 수요가 있을 수 있어 Phase 2 이후 확인 필요)
- 미리보기 화면에서 표지 문구·목적 문안 등은 자유 수정 후 최종 확정/내보내기

### 4.9 예산 관리 (신규 — 사업계획서 분석으로 추가)

사업계획서를 보니 예산은 비목(인건비/운영비/여비/업무추진비) 체계로 짜여 있고, 그중 상당 부분이 "과정별 강사료·실습장비·다과비"처럼 **커리큘럼 빌더의 데이터와 1:1로 연결되는 항목**이었습니다. 따라서 빌더에서 과정을 설계하는 순간 예산이 함께 추정되도록 연동합니다.

- **비목/세목 마스터**: 인건비(보수/일용임금), 운영비(일반수용비/공공요금/임차료/시설장비유지비), 여비(국내/국외), 업무추진비(다과비/회의운영비) 등 표준 비목 체계 등록
- **과정별 자동 산정 항목**
  - 강사료 = 등급별 단가(4.1) × 시간 × (주강사/보조강사 인원수)
  - 실습장비 임차료 = 1인당 단가 × 수강 인원
  - 다과/중식비 = 1인당 단가 × 일수 × 수강 인원
  - 교육장 임차료(외부 장소 사용 시) = 일/회 단가 × 일수
- **예산총괄표·세부예산 집행계획 자동 생성**: 빌더에서 설계한 모든 과정의 합산 결과를 사업계획서 양식(비목-세목-세부산출내역-금액-비율)으로 자동 표 생성, 총사업비 대비 비율 자동 계산
- **집행률 대시보드**: 사업 진행 중 실제 지출을 입력하면 계획 대비 집행률을 시각화 (사업계획서의 "사업비 집행 실적 95% 목표"와 연동)
- **자부담 기준표 관리**: 과정 운영비 구간별·기업 규모별(대기업/중견기업 vs 중소기업/프리랜서) 자부담금 테이블을 마스터로 관리하고, 과정 등록 시 자동 매칭되도록 지원

### 4.10 성과지표(KPI) 관리 (신규)

사업계획서의 "필수/선택 성과지표" 체계를 그대로 시스템 기능으로 옮깁니다.

- **지표 마스터**: 지표명, 논리속성(투입/과정/산출/결과), 가중치(%), 측정방법, 목표치, 목표치 설정근거를 등록 (예: 최종 수료생 수 90명/30%, 교육생 만족도 85%/30%, 현업 적용률 30%/20%, 직무 역량 향상도 30%/20%, 사업비 집행실적 95%)
- **실적 입력 및 자동 집계**: 4.6(강사 피드백)·4.7(수강생 후기) 데이터와 연동해 수료율·만족도(회수율 포함)·현업적용률을 자동 계산, 직무역량향상도처럼 인터뷰/추적이 필요한 지표는 수동 입력 지원
- **목표 대비 실적 대시보드**: 사업 진행 중 지표별 달성 추이를 시각화, 목표 미달 위험이 있는 지표는 조기 경고
- **성과지표 기술서 자동 생성**: 사업계획서의 "성과지표 기술서" 양식(정의/논리속성/가중치/측정방법/연계성/설정근거)을 마스터 데이터 기반으로 자동 채워 생성

### 4.11 추진일정(WBS) 및 홍보계획 관리 (신규)

사업계획서의 "세부추진 일정계획"과 "연간 홍보 계획"을 캘린더/체크리스트 형태로 관리합니다.

- **사업 단계 템플릿**: 사업비신청 → 교육실무위원회 → 강사섭외/커리큘럼구성 → 교육홍보 → 교육운영 → 교육성과분석 → (중간보고) → 최종평가/정산 → 자료제출, 각 단계를 과정별로 자동 생성된 체크리스트로 관리하고 담당자·기한 지정
- **간트 뷰**: 월별로 어떤 과정이 어느 단계에 있는지 한눈에 확인 (예: "4월=1과정 운영 중, 2과정 홍보 중, 3과정 강사섭외 중"처럼 여러 과정이 동시에 다른 단계로 진행되는 것이 실제 패턴이었습니다)
- **홍보 일정 관리**: 매체(팩스/이메일/홈페이지 배너/잡지·신문 기고)별 발송 예정일과 발송 이력을 관리하고, 발송 대상(각 사 교육담당자 메일링리스트)과 연동
- **교육실무위원회 회의록**: 회차별 회의 일정, 안건, 결정사항을 간단히 기록해 사업 운영 이력으로 누적

### 4.12 사업계획서/결과보고서 자동 생성 (신규)

4.8(개별 과정 안내문)보다 한 단계 위, **연간 사업 전체를 아우르는 공식 문서**를 자동 생성하는 기능입니다. 업로드해주신 사업계획서가 정확히 이 산출물의 표준 양식이었습니다.

- **자동 매핑되는 장(章) 구성**
  - I. 개요: 요약서(세부사업명/기간/총사업비/총괄책임자/정량·정성 목표), 전체 교육계획(안) 표(과정별 운영횟수·인원·일정·장소를 모든 교육과정 데이터에서 합산), 추진전략, 기대효과
  - II. 교육사업 내용: 전체 교육(안) 표 + 과정별 세부 운영계획(4.8의 과정별 안내문 내용을 그대로 재사용)
  - III. 사업관리: 추진절차(거버넌스 다이어그램), 세부추진 일정계획(4.11 데이터)
  - IV. 예산 관리 및 집행: 예산총괄표·세부예산 집행계획·비용집행기준(4.9 데이터)
  - V. 신청사 현황: 기관 프로필, 조직도, 투입인력현황(4.1의 기관 마스터 데이터 재사용), 주요 사업실적 이력
- 매년 반복되는 V장(기관현황)과 비용집행기준표는 마스터 데이터로 고정해두고 연도만 갱신하면 되도록 설계해, 매년 새로 타이핑하지 않아도 되게 합니다.
- 사업 종료 후에는 동일한 데이터 구조에 "실적치"를 채워 결과보고서를 같은 방식으로 생성

Coordinator (운영 담당자, 강사와 별도 역할)
 ├─ name, title, email, phone

RecruitmentPolicy (모집/운영 정책 기준값)
 ├─ capacity(정원), fee_policy(무료/유료), meal_support, parking_support
 ├─ application_method(선착순/심사), application_rounds[] (차수별 대상조건·일시)
 ├─ required_documents[]
 └─ self_pay_table_ref (자부담 기준표)

FixedSessionTemplate (고정 세션 템플릿)
 ├─ type(오리엔테이션/중식/설문종료), default_duration, default_position(첫날 시작/매일/마지막날 종료)

CurriculumProject (= 교육과정/세미나 1건)
 ├─ program_ref (소속 사업)
 ├─ title, topic, target_days, location, capacity, target_level, online_available
 ├─ CourseOverview
 ├─ recruitment_policy_ref, coordinators[] (복수)
 ├─ Day[]
 │   └─ Slot[] (course_card_ref | fixed_session_ref, instructor_ref, start, end, memo)
 └─ status (초안/확정/진행완료)

TrainingSession (실제 진행된 교육 1회차)
 ├─ curriculum_project_ref, actual_date, location
 ├─ InstructorFeedback (잘된점/개선점/추가교육제안)
 ├─ TraineeFeedback[] (만족도, 자유의견)
 └─ ApplicationCaseStudy[] (후속 적용사례)

OrganizationProfile (기관 프로필, 신규 — 연도별 재사용)
 ├─ basic_info(기관명/사업자번호/주소/연락처), org_chart, staff[]
 └─ track_record[] (연도별 사업명/기간/계약금액/발주처)

## 7. 화면 구성 개요

- **대시보드**: 진행 중/완료된 커리큘럼 프로젝트 목록, 다가오는 교육 일정
- **사업 대시보드 (신규)**: 연간 사업 단위로 예산 집행률, KPI 달성 현황, 소속 교육과정들의 진행 단계(간트)를 한 화면에서 확인
- **과정 Pool 관리**: 카테고리 트리 + 카드 그리드 + 색상/아이콘 범례
- **커리큘럼 빌더**: Pool(좌) + 일자별 바구니(우) + "AI 초안 생성" 버튼 + 시간/충돌 경고 영역 + 실시간 예상 강사료 합산
- **강사 Pool 관리**: 강사 카드 목록, 등급/단가 표시, 스케줄 캘린더, 자료실
- **예산 관리 화면 (신규)**: 비목/세목별 예산총괄표, 과정별 자동산정 내역, 집행률 차트
- **성과지표 관리 화면 (신규)**: 지표별 목표 대비 실적 게이지, 성과지표 기술서 미리보기
- **추진일정/홍보 화면 (신규)**: 월별 간트 뷰, 홍보 매체별 발송 캘린더
- **사후관리 화면**: 진행 완료된 교육의 강사 피드백 타임라인, 과정별 개선 이력
- **수강생 후기/적용사례 아카이브**: 검색·필터 가능한 후기 목록, 우수사례 하이라이트
- **문서 출력 화면**: 과정 안내문(4.8) / 사업계획서·결과보고서(4.12) 미리보기 및 내보내기

- **데이터 이력 관리**: 과정 카드, 커리큘럼 변경 이력을 추적 가능하도록 버전 기록

## 10. 추가 제안 아이디어 (제 의견)

1. **과정 조합 추천 엔진**: 과거 커리큘럼에서 자주 함께 배치된 과정 조합을 분석해 "이 과정과 자주 같이 쓰입니다" 형태로 추천하면 신규 기획자도 빠르게 양질의 초안을 만들 수 있습니다.
2. **난이도 흐름 검증**: 초급→중급→고급 순서가 일자별로 자연스럽게 점증하는지 AI가 검토해 "2일차에 난이도가 급격히 올라갑니다" 같은 경고를 제공.
3. **강사 부하 분산 히트맵**: 특정 강사에게 일정이 몰리지 않는지 캘린더 히트맵으로 시각화.
4. **사전 수준진단 설문 연동**: 교육 시작 전 수강생 대상 사전 설문으로 실제 수준을 파악해, 계획된 난이도가 적절한지 사전에 점검.
5. **커리큘럼 버전 비교**: 동일 주제로 여러 차례 진행한 커리큘럼들을 나란히 비교해 시간 배분/만족도 변화 추이를 확인.
6. **예산/강사료 자동 합산**: 과정별 강사료를 입력해두면 커리큘럼 확정 시 총 예산이 자동 계산되어 행정 처리에 활용.
7. **공문/안내문 자동 생성**: 확정된 커리큘럼을 PDF나 문서 형태의 교육 안내문으로 바로 내보내는 기능. (→ 4.8로 정식 기능화)
8. **강사 로테이션 자동 배치**: 실제 샘플에서도 강사 2인이 오전/오후, 1일차/2일차로 번갈아 배정되는 패턴이 보였습니다. 다일 과정에 강사가 여러 명일 때 한쪽에 부담이 몰리지 않도록 교차 배치를 자동 제안하는 기능.
9. **예산 시뮬레이션**: 커리큘럼 빌더에서 카드를 추가/삭제할 때마다 예상 강사료·장비비가 실시간으로 갱신되도록 해서, "이 구성대로 가면 예산이 얼마 남는지"를 기획 단계에서 바로 확인할 수 있게 합니다.
10. **신규 강사 등급 추천**: 강사를 처음 등록할 때 소속·경력연수·학위를 입력하면 사업계획서의 등급 기준표(책임급A/선임급B/원급C 등)에 맞춰 등급을 자동 추천 — 다만 최종 등급 확정은 항상 담당자가 결정.
11. **사별 모집 균형 자동 점검**: 사업계획서에 "사별 인력 현황 기반 균형 배분" 원칙이 명시되어 있었습니다. 접수 현황이 특정 방송사에 쏠리면 경고하고 잔여 정원을 안내하는 기능.

- **정책 연계**: 경기도 인력양성 사업과 연계되어 지역·소속 기준 접수 차수가 분리되어 있음

### 부록 B: "2026년도 AI 방송직군별 역량강화 사업계획서" 분석 요약

업로드해주신 사업계획서(2026년 3월, 총사업비 1.7억원)에서 확인한 구조입니다.

## 12. 리스크 및 고려사항

- AI가 생성한 초안이 기계적인 조합에 그쳐 실제 교육 효과와 맞지 않을 수 있으므로, 항상 "초안 제안 + 사람 최종 확정" 구조를 유지해야 합니다.
- 강사 개인정보(이메일, 연락처)는 접근 권한 관리가 필요합니다.
- 피드백 데이터가 쌓이기 전(Phase 1~2)에는 과정 카드의 "추천 신뢰도"가 낮을 수 있으므로, 초기 데이터 입력 단계에서 기존 경험 기반 정보를 충분히 채워 넣는 것이 중요합니다.
- 다수 담당자의 동시 편집 시 데이터 정합성 확보가 필요합니다.
- **민감 개인정보 처리 주의**: 사업계획서 원본의 "수행인력 이력서"에는 주민등록번호가 포함되어 있었습니다. 시스템의 기관 프로필/인력현황 마스터(5장 `OrganizationProfile.staff`)는 이런 식별번호를 저장하지 않도록 설계하고, 실제 제출용 이력서 파일이 필요하다면 암호화된 별도 파일 첨부 방식으로만 다루는 것을 권장합니다.
- **예산 자동산정의 한계**: 강사료·임차료 등은 등급표·단가표 기준으로 추정치를 자동 계산하지만, 실제 계약 단가는 협의로 달라질 수 있으므로 "추정 예산"과 "확정 집행액"을 구분해 관리해야 합니다.
- **사업 vs 과정 권한 분리**: 예산·KPI는 사업 단위로 총괄책임자만 수정 가능하게, 커리큘럼 구성은 교육기획 담당자가 자유롭게 수정 가능하게 권한을 분리해야 책임 소재가 명확해집니다.
